One funny single-line excuse a developer gives when code breaks in
production — the twist being that the green build was green only
because the test that would have caught the bug was commented out
to make the build green.

## The excuse

> The tests all passed because the one test that would have caught this is the one I commented out to make them pass.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) writes the excuse line to
`/output/entry.txt`, byte for byte the same on every run. No network,
no randomness, no trailing newline.
